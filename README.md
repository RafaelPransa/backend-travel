Sistem Reservasi PT. Rini Trans Putri

Proyek ini adalah sistem backend untuk manajemen reservasi kendaraan pada PT. Rini Trans Putri. Sistem ini dibangun menggunakan Node.js, Express.js, dan PostgreSQL untuk memastikan manajemen transaksi yang aman, efisien, dan bebas dari _double booking_.

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **ORM/Driver:** pg (node-postgres)
- **Development Tools:** Nodemon, Thunder Client (API Testing)

## 🚀 Cara Menjalankan Project

### Prerequisites

Pastikan kamu telah menginstal:

1. [Node.js](https://nodejs.org/)
2. [PostgreSQL](https://www.postgresql.org/)

### Instalasi

1. Clone repository ini atau download folder proyek.
2. Masuk ke folder backend:
   ```bash
   cd backend
   ```
3. Install dependencies:

   ```bash
   npm install
   ```

4. Pastikan PostgreSQL berjalan dan database sudah disiapkan sesuai skema yang ada.
5. Jalankan server dalam mode development:

   ```bash
   npm run dev
   ```
